Junior Data Engineer – Exemplu Tech (Cluj-Napoca, hibrid)

Căutăm un Junior Data Engineer care să ne ajute să construim platforma de date.

Responsabilități:
- Construiești și întreții pipeline-uri ETL/ELT în Azure Data Factory și dbt
- Modelezi date pentru raportare în Power BI
- Scrii SQL performant și scripturi Python pentru transformări
- Implementezi verificări de calitate a datelor
- Lucrezi cu echipele de business pentru a înțelege cerințele

Cerințe obligatorii:
- 2+ ani experiență cu SQL și Python
- Experiență cu Power BI sau alt instrument de BI
- Engleză la nivel avansat

Constituie un avantaj:
- Azure Data Factory, Databricks sau PySpark
- dbt
- Git și CI/CD
